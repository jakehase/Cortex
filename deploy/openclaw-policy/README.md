# Canonical OpenClaw policy fragments

These files are the source-controlled policy sections for the live OpenClaw workspace files of the same names. They intentionally contain no credentials or unrelated personal memory.

Deployment is merge-oriented:

1. Back up the live `USER.md`, `TOOLS.md`, and `MEMORY.md` with owner-only permissions.
2. Replace active statements that require personal OAuth, `ultra`, or forced Fast/priority routing with the matching current statements in these fragments.
3. Preserve the old text as explicitly superseded history, using the dated supersession edges in `MEMORY.md`; do not leave the old rule co-current.
4. Merge the attachment boundary into `TOOLS.md` without removing supported image/document workflows.
5. Confirm each live file has one active answer for OAuth account, model, default reasoning, and service tier before restarting anything.

Do not wholesale replace the live files with these fragments: unrelated user preferences, tool notes, and durable memory must remain intact.

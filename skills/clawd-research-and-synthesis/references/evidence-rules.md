# Evidence rules

## Source priority by question type

### Current external facts
Prefer:
1. live web or system source
2. current artifact or live command output
3. memory only for background

### Workspace/project state
Prefer:
1. canonical artifact or file
2. live command output when the fact is volatile
3. memory only for orientation

### Preferences and durable context
Prefer:
1. memory
2. stable workspace docs like `USER.md`, `MEMORY.md`, `TOOLS.md`
3. chat context

## What to say

### Safe phrasing
- "Observed in the artifact"
- "Current file shows"
- "Memory says, but I have not live-verified"
- "Best current evidence suggests"

### Unsafe phrasing
- "Definitely" when the evidence is indirect
- "Current" when the fact is only from memory
- "Passed" when only partial artifacts were checked

## Synthesis rule

A good answer usually needs:
- one direct answer sentence
- two to four concrete evidence bullets if the question is important
- one recommendation or next step

# Approval boundaries

## Usually safe without extra approval
- reading files
- internal workspace edits
- local commands
- web research
- reading external systems when the user clearly asked for information from them

## Usually ask first
- sending emails
- sending messages to other people
- public posts or replies
- calendar changes that create, cancel, or move events
- document edits in shared/public systems when not explicitly requested
- destructive actions on external systems

## Draft vs send rule

If the user asked for help composing but not clearly sending:
- prepare the draft
- do not send it

If the user clearly said to send/post/do the external action:
- execute if the system/tool is available and policy allows
- report success or blocker clearly

## Smart-home note

Home Assistant actions are external actions, but usually lower-friction than messaging or public posting.
Still be clear when you are changing state versus just checking status.

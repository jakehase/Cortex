# Write destinations

## `memory/YYYY-MM-DD.md`
Use for:
- day-by-day factual notes
- meaningful completed work
- blockers
- decisions from the session
- short artifact pointers

## `MEMORY.md`
Use for:
- curated durable preferences
- recurring user guidance
- stable lessons
- long-term context worth carrying forward

Do not use for:
- noisy logs
- rapidly changing status
- raw telemetry

## `memory/projects/<project>.md`
Use for:
- canonical ongoing project state
- current blockers
- next trustworthy step
- project-specific working truth

## `TOOLS.md`
Use for:
- environment-specific operational details
- names, endpoints, device labels, voice prefs, SSH aliases

## Rule of thumb

Write the smallest durable thing that future-you will actually need.

# Agent Work v1.0.0 Release Notes

Release tag: `agent-work-v1.0.0`
Fidelity: `production_slice`
Audience: private/internal

## Released

- One stable `agent-work plan|run|status|resume|cancel|verify|report|doctor|replay` command family.
- Canonical facade composition for planning, execution, verification, operations, release-candidate qualification, and final release truth.
- Fail-closed control-plane/execution-plane boundary.
- Persistent objective-driven continuation, durable recovery, fenced workers, patch admission, claim integrity, and independent verification.
- Four-class qualification: shared-stack self-dogfood, AI OS product platform, bounded clone/parity slice, and brownfield transfer.
- Deterministic, fault, clean-room, 4/8/12-worker-tier, and corrected six-hour real-work qualification evidence.
- Versioned Phase 9 surface matrix and release packet.

## Routing change

The supported CLI moved from `apps/system-benchmark/canonical-agent-work.mjs` to `apps/agent-work/cli.mjs`. The old path remains a warning-emitting compatibility wrapper. Synthetic Labor OS remains compatibility/evidence-only.

## Exact boundary

This release is not public GA, production deployment, universal parity, or full-clone proof. The corrected soak proved an aggregate 12-worker tier and 243 waves over 361.06 minutes, while observed peak physical concurrency remained 2 because provider calls were bundled. External actions remain denied by default.

See `MIGRATION_AND_ROLLBACK.md` for migration and fallback procedures and the release packet for the final source digest and independent-review evidence.

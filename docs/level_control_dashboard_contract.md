# Level Control Dashboard Contract (v1)

## Status taxonomy
- `planned`: level defined but no reachable canonical endpoint.
- `implemented`: canonical endpoint reachable but verification requirements incomplete.
- `verified`: endpoint reachable + tests passing + watchdog healthy + owner and runbook assigned.
- `degraded`: endpoint exists but currently unhealthy OR verification control failing (tests/watchdog).
- `deprecated`: intentionally sunset; excluded from active health score.

## Tier model
- `core`: always-on control plane levels.
- `domain`: normal production capability levels.
- `experimental`: exploratory/optional levels.

## Snapshot source of truth
Generated by `tools/level_control_snapshot.py` into:
- `reports/level_control_dashboard/latest.json`
- `reports/level_control_dashboard/snapshot_<timestamp>.json`

## Required per-level fields
- endpoint_exists
- endpoint_reachable
- tests_present
- tests_last_pass
- watchdog_present
- watchdog_healthy
- owner
- runbook

## Health score model
Weighted model:
- endpoint: 30%
- tests: 25%
- watchdog: 20%
- drift_supervisor: 15%
- governance completeness: 10%

## Drift delta
`drift_delta = current_overall_health_score - previous_snapshot_overall_health_score`

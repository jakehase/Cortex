# Start here

If you only read one page, read this one.

## What Cortex + OpenClaw is

Cortex + OpenClaw is a modular super-agent stack.

- **Cortex** is the cognition layer
- **OpenClaw** is the execution/runtime layer

Together, they form a persistent agent runtime that can:
- chat across channels
- browse and research
- remember durable context
- delegate work to subagents and coding sessions
- schedule and automate tasks
- operate across multiple sessions and tools

## Why this is not just another agent framework

The distinctive claim is not that the system has tools, memory, or browser access.
A lot of systems have those.

The distinctive claim is that Cortex is trying to combine:
- **cognitive routing** instead of a flat agent loop
- **L2 browser/discovery** as part of a larger research chain
- **epistemic memory** instead of plain similarity recall
- **capability reality-checking** before reinvention
- **explicit failure semantics** instead of smooth-looking lies
- **control-plane / self-audit** ideas around implementation reality

## The shortest mental model

```text
OpenClaw = execution/runtime
Cortex   = cognition/routing/memory/browser/validation
```

## The shortest research model

```text
Discover -> Contextualize -> Validate -> Synthesize
```

## The shortest memory model

```text
Fast recall -> Reconcile -> Investigate -> Clean-but-empty if needed
```

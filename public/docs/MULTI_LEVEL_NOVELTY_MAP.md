# Multi-level novelty map

The novelty of Cortex is distributed across the level system, not concentrated in one component.

## Core idea

The interesting part is not merely that many levels exist.
The interesting part is that different levels participate in distinct **cognitive and orchestration roles**, and that the system explicitly composes them into patterns.

## Major novelty clusters

### L2 — browser / discovery
- browser-first research grounding
- query-only discovery vs URL-targeted browse
- discovery as the first stage of a larger chain

### L7 + L22 — memory / retrieval
- retrieval and contextualization layers
- movement toward epistemic memory rather than plain similarity recall
- memory as part of a broader research and reasoning pipeline

### L9 + L15 + L32 + L34 — architecture / deliberation / synthesis / validation
- structured higher-order chains
- explicit design/critique/synthesis/validation composition
- stronger multi-step reasoning paths than a flat answer loop

### L13 + L29 + L32 + L34 — creativity governor path
- high-variance idea generation
- reframing and naming
- synthesis of non-obvious survivors
- validation/anti-anchor checks

### L24 — orchestration / routing
- route selection as cognition
- explicit chain selection and routing markers
- coordination of multi-level paths

### Control-plane / capability guard
- implementation-state checking
- capability registry/preflight thinking
- distinction between coded, live, verified, blocked

## Why this matters

A normal agent framework may have tools and workflows.
Cortex is trying to make the level system itself part of the architecture story.

That means novelty lives in:
- the composition of levels
- the routing logic between them
- the guardrails and control-plane checks around them
- the explicit orchestration patterns they create

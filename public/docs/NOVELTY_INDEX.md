## Summary

Cortex is not novel because it has tools, memory, or browsing.
It is novel insofar as it combines:
- routed cognition
- layered research
- epistemic memory
- capability reality-checking
- explicit failure semantics
- self-audit/control-plane discipline

That is the architecture story the repo should tell clearly.
